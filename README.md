# Startup Funding Analysis — SQL Data Analytics Project

## Project Overview

This project uses **SQL and MySQL** to analyze startup funding data and identify investment trends across industries, cities, investors, funding types, and time periods.

The goal is to understand how startup funding is distributed, identify highly funded industries and startups, and explore yearly and monthly funding patterns using SQL queries.

## Dataset

The project uses `startup_funding.csv`, which contains information about startup names, funding dates, industries, locations, investors, investment types, funding amounts, and remarks.

## Key Analysis Areas

- Overall startup funding statistics
- Unique startup counts and funding records
- Industry-wise and city-wise funding analysis
- Investment type distribution and data cleaning
- Top-funded startups and investor activity
- Year-wise and month-wise funding trends
- Average funding by industry
- Above-average funding rounds

## Tools and Technologies

- **MySQL** — Data analysis and querying
- **SQL** — Aggregation, filtering, grouping, sorting, subqueries, and date-based analysis
- **CSV** — Dataset storage

## Key Learnings

- Writing SQL queries to answer business questions
- Analyzing funding trends using aggregate functions
- Cleaning inconsistent categories and handling missing values
- Understanding the difference between funding records and unique startups
- Interpreting data carefully and identifying data-quality limitations

## Conclusion

This project demonstrates how SQL can be used to transform raw startup funding records into meaningful business insights. It provides a foundation for further analysis and future dashboard development.
